# Engineering model and units

Build oriented branch incidence A and D=diag(1/(x tap)). B=AᵀDA. Remove one slack row/column and solve PTDF=D Ared Bred⁻¹. A unit injection is balanced by slack withdrawal. For outage k, h=PTDF[:,fromk]−PTDF[:,tok] and LODF[:,k]=h/(1−hk), diagonal −1. Detect graph bridges before division; islanding factors are null. AC contingency limits are evaluated from a fresh damaged-network solve. Reactive reserves = aggregate Qmax−Qrequired and Qrequired−aggregate Qmin.

Network powers use MW/MVAr, branch impedances and taps use the stated system per-unit base, bus voltage is per unit, angles are degrees at interchange and radians inside equations. Loads draw positive P/Q; inverter and generator positive Q means injection. Transformer branch direction matters. Equipment source ratings must be verified for the project.

Balanced positive-sequence static studies; no transient stability, cascading protection or frequency assessment. An island is statically supplied only with a valid reference; promotion of a reference-capable generator is an explicit assumption, not automatic proof that a real island can form. Nonconverged scenarios remain unknown. Real-power adequacy is unknown when Pmax is absent. Reactive output is unknown in DC mode. PTDF/LODF are single-connected-island lossless DC incremental factors with fixed taps and shifts; bridge outage columns are null. P–V/Q–V scans are sampled solves and a failed solve does not prove collapse. Continuation keeps PV types fixed and disables Q-limit switching. Corrective actions are enumerated evaluations, not an optimizer or redispatch guarantee.

Primary references, consulted 2026-10-24: [MATPOWER PTDF documentation](https://matpower.org/documentation/ref-manual/legacy/functions/makePTDF.html), [MATPOWER LODF and bridge masking](https://matpower.org/documentation/ref-manual/legacy/functions/makeLODF.html). These references define sensitivity applicability; this is a standalone implementation.
